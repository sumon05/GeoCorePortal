# GeoCorePortal

GeoCorePortal is a full-stack WebGIS application for managing geotechnical projects, boreholes, and geological interval data.

🚧 **Project Status**

The project is currently under active development.

- ✅ The **frontend** is functional and demonstrates the application's user interface and core GIS features. [GeoCorePortal Frontend](https://github.com/sumon05/GeoCorePortal/tree/main/frontend)
- 🚧 The **backend** is currently under active development and is being integrated with the frontend through a REST API and PostgreSQL database.

---

## Current Features

- Interactive map using Leaflet
- Borehole visualization
- Project selection
- Geological interval display
- Coordinate transformation (ETRS89 / UTM32 → WGS84)
- Borehole search
- Dataset statistics
- Responsive user interface
